# Obsidian 的十一个视图

面板左上角是「今天 ▾」菜单，十一个视图分四栏。分栏不按功能分类，按**你想干什么**分。

## 现在

| 视图 | 一句话 |
|---|---|
| 今天 | 今天写了多少、最近有没有断、还有一件你现在就能做的事。底部能直接导出这一周的图。 |
| 惦记 | 你自己说要在意的那几件事，横着看是时间，缺一块就是那几天没碰。 |

「惦记」是这一版的主角。你写下 3–8 条要在意的事（比如「练琴 | #练琴 | 每周 3 次」），它给你一条时间带，缺的那几天一眼就能看见。全页面只有这一处会说一句话提醒你，而且可以推迟。

## 时间

| 视图 | 一句话 |
|---|---|
| 概览 | 全部历史的总量、节奏和热力图。 |
| 知识地层 | 每个月写下的东西像沉积岩一样堆起来，越厚说明那个月写得越多。 |
| 月相日历 | 把每个月想成一个月亮：亮面是写完的比例，半途而废的月份是残月。 |
| 年度画像 | 一年一年摆在一起比，看你在哪个月最厚。 |

## 内容

| 视图 | 一句话 |
|---|---|
| 知识复盘 | 把该回头看的笔记挑出来，替你复习。 |
| 笔记地图 | 你的笔记长什么样：孤儿、断链、标签和目录分布。 |
| 洞察 | 写作时辰、相似标题、标签搭配这类不太好一眼看出来的东西。 |

「笔记地图」管六件事：目录分布、标签云、孤儿笔记（没人链、也没链别人）、断链（链到不存在的笔记）、找笔记、导出 Markdown 索引。

## 做事

| 视图 | 一句话 |
|---|---|
| 速记 | 随手记一句，不用新建一篇笔记。 |
| 数据 | 所有原始数字都在这里，也能导出；周报卡能一键出图。 |

速记支持搜索、就地编辑、导出。数据页是唯一放原始数字的地方——贡献分在这里，不在门面上。

## 材质与画风

头部有两组开关，都不进设置页：

**材质**（两档，点了立刻生效）

- 毛玻璃 — 默认，背景模糊 22px
- 亚克力 — 更透，带一层细颗粒

**画风**（四档，循环切换）

像素 → 水墨 → 单色 → 星空

材质和画风是两件事：材质管面板本身怎么透，画风管里面的图形怎么画。系统不支持背景模糊时会自动退回实心，`prefers-reduced-motion` 打开时会关掉全部动画。

## 分享卡

数据页有「导出分享卡」，生成一张 1080×1440 的 PNG，外加一份 SVG。只含八项统计，不含任何笔记标题。旁边还有「复制分享文案」。

## 周报

1.2.0 起，**今天**页底部有两个按钮：

- 导出这一周的图 — 1080×1440 的周报 PNG（再加一份 SVG），落到 `Pulse/导出/Pulsewright-周报-<日期>.png`
- 复制周报文字 — 把这一周写成一段话，直接粘到哪都行

数据页也有一张「周报」卡，同样的两个按钮。图里只有统计：本周得分、活跃天数、字数、笔记数、链接数、最厚的一天，**不含任何笔记标题**。周窗口按 ISO 周算（周一到周日），报告日期取今天，不会写成一周还没过完就「截至周日」。

导出位置：

```
<你的库>/<数据目录>/导出/
```

## 命令

命令面板里搜 `Pulsewright`，有七个：

| 命令 | 作用 |
|---|---|
| 打开面板 | 打开主视图 |
| 重新扫描 | 丢掉缓存重扫全库 |
| 导出 CSV | 导出日统计 |
| 导出 JSON | 导出全部数据（可脱敏） |
| 快速速记 | 直接跳进速记页 |
| 笔记地图 | 直接跳进地图页 |
| 洞察 | 直接跳进洞察页 |
