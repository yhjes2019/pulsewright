# Zotero 的六问

你收藏的论文很多，读完的很少。六问不替你做笔记，它只问六个你本来就应该问自己的问题——按 1→7 走一遍，就是一次精读。

## 七段

| # | 段 | 它给你什么 |
|---|---|---|
| 1 | 这本文献讲了什么 | 类型 · 期刊 · 年份，摘要（可展开），有没有 PDF |
| 2 | 我为什么选它 | 一个输入框 + 四个预设理由 |
| 3 | 库里有相关的吗 | 按相似度排出的同主题文献，带百分比 |
| 4 | 有没有更优解 | 拿最相似的一篇做逐行对比，可换一篇 |
| 5 | 读完还有哪些问题 | 一个输入框 |
| 6 | 下一本该读什么 | 库内还没读、但跟你读过的相近的三篇 |
| · | 你的阅读痕迹 | 批注总数、集中在前面/中间/后面、有评论的几条 |

## 一篇一篇读下去

面板右上角有「‹ 上一篇 / 下一篇 ›」，按**文献列表当前的排序**走，不用关掉再点下一条。
翻到列表两头会提示「已经是这个列表的第一篇 / 最后一篇」。

排好序（比如按年份）再打开，就是一条自然的阅读路线。

## 面板材质

面板右上角可以在**毛玻璃**和**亚克力**之间换。只影响观感，不影响内容；
系统关了半透明效果时会自动退回实心底。

## 第 2 问的四个预设理由

「导师推荐」「综述里引到」「方法可借鉴」「想复现这个实验」——点一下就直接填进输入框，省得对着空白发呆。也可以自己写。

## 相似度是怎么算的

不是调模型，是词频。

1. 把每篇文献的**标题 + 摘要 + 期刊 + 标签 + 其他字段**拼成一段文本，去掉 HTML 标签
2. 分词：英文按词（≥3 字母、去停用词），中文按**重叠二元组**（「刻意练习」→ 刻意 / 意练 / 练习）
3. 算 TF-IDF，每篇变成一个向量
4. 两两算余弦相似度

故意**不把添加日期、修改日期算进去**——同一篇论文重新导入一次，不该变成另一篇。

所以第 3 问说「库里还没有和它词面相近的条目」时，不是没算，是真的没有词面上相近的。

## 状态标签

每一问右上角会告诉你它现在什么状态：

- **自动带出** — 这一段不用你写，它已经从库里读出来了
- **待你写** — 需要你说一句
- **已答** — 你写过并保存了
- **点一条可跳过去** — 下面列的是可点的文献
- **库里还太少** — 条目不够，算不出有意义的比较

## 答案存在哪

存在**这篇文献的子笔记**里，开头带标记 `<!-- pulsewright-six -->`。

第 2 问和第 5 问写完点「保存到子笔记」，两段会合并成一条笔记：`<h2>我为什么选它</h2>` 和 `<h2>读完的问题</h2>`。

重复保存是更新同一条，不会越堆越多。

## 底部动作条

- **在 Zotero 里打开** — 跳到条目本身
- **复制 DOI**
- **看批注** — 有 PDF 附件时直达批注

`Esc` 关闭面板。

## 为什么要手动点开

因为它不该在你点开每篇文献时都弹出来。四个入口都要求你先选中一条文献——这是有意的：六问是「我要认真读这一篇」时做的事，不是浏览时自动跳出来的东西。
