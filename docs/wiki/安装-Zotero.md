# 安装 · Zotero

需要 Zotero **7.0 – 10.x** 桌面版。

> Zotero 目前**没有官方插件目录**（官网写明「目录在计划中」），所以只能手动装。

## 装 `.xpi`

1. 从 [Releases](https://github.com/yhjes2019/pulsewright/releases) 或仓库 `zotero/` 目录拿到 `pulsewright-<版本>.xpi`
2. 打开 Zotero → 工具 → 插件
3. 点右上齿轮 → **Install Plugin From File…**
4. 选那个 `.xpi`
5. 重启 Zotero

装好后工具菜单里会多一项「六问」，工具栏会多一个脉搏图标。

## 四个入口

同一件事，四条路，你用哪条都行：

| 入口 | 位置 |
|---|---|
| 工具菜单 | 工具 → 六问 |
| 右键菜单 | 在文献条目上右键 → 六问 |
| 工具栏 | 条目列表上方的脉搏图标 |
| 快捷键 | `Ctrl+Shift+6`（Mac 是 `Cmd+Shift+6`） |

四个入口都要**先在文献列表里选中一条文献**。选中附件或笔记时打开会提示「六问只对文献条目显示」。

## 它把答案放在哪

你的作答不会另建数据库，而是写进**该文献的子笔记**，笔记开头带一个标记：

```html
<!-- pulsewright-six -->
```

所以：

- 换台电脑同步 Zotero 库，答案跟着走
- 关掉插件，答案还在
- 同一篇文献重复保存会更新同一条笔记，不会越堆越多

## 它读什么

只读你这台机器上 Zotero 库里的元数据：标题、摘要、类型、期刊、年份、DOI、标签、分类、批注、附件有无。

不发网络请求。不加任何字段到你的条目上。

## 卸载

工具 → 插件 → 选中 Pulsewright → Remove。已经写下的子笔记不会被删。
