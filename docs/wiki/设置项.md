# 设置项

设置 → 第三方插件 → Pulsewright → 选项。

| 设置项 | 默认 | 说明 |
|---|---|---|
| 数据目录 | `Pulse` | 日统计、速记、导出都放这里。改之前建议先导出一次。 |
| 数据保留天数 | `0` | 0 = 永久保留。设成 90 就只留最近 90 天，超出的日条目在扫描结束时被裁掉。 |
| 单篇词数上限 | `4000` | 防止一篇长文把当天字数拉爆。超出部分不计。 |
| 贡献分封顶 | `120` | 一天最多算这么多。 |
| 排除的目录 | `.obsidian` `.trash` `templates` | 逗号分隔。 |
| 排除的属性字段 | 空 | 带这些 frontmatter 字段的笔记不计入统计，大小写不敏感。用于排除模板、草稿、转述。 |
| 久未更新阈值 | `90` 天 | 超过这么多天没修改，「知识复盘」会把它挑出来。 |
| 实时跟踪 | 开 | 关掉后只在手动「重新扫描」时更新。 |
| 编辑会话间隔 | `5` 分钟 | 两次编辑隔超过这个时间，算新的一段会话。用来算「真实坐下来写了多久」。 |
| 权重 · 每多少字计 1 分 | `200` | 贡献分的四项权重，逐个可调。 |
| 权重 · 每篇笔记 | `4` | |
| 权重 · 每处链接 | `1.5` | |
| 权重 · 每次修订 | `1` | |
| 面板材质 | 毛玻璃 | 也可在面板头部直接点，见 [Obsidian 的十一个视图](Obsidian-十一个视图) |
| 惦记的线 | 空 | 一行一条：`名称 \| 匹配 \| 每周几次` |
| 导出含设置 | 关 | 打开后导出的 JSON 会包含全部设置。默认不含。 |
| 备份含速记 | 关 | 打开后备份会包含速记内容。默认不含。 |

## 贡献分怎么算

```
分 = 字数 / 每多少字计1分
   + 笔记篇数 × 权重
   + 链接数   × 权重
   + 修订次数 × 权重
```

结果再按「贡献分封顶」截断。默认权重下，1000 字 + 2 篇 + 4 处链接 + 1 次修订 = 20 分。

## 惦记怎么写

一行一条，竖线分隔：

```
练琴 | #练琴 | 3
读论文 | #论文 | 5
```

意思是：这条线叫「练琴」，看带 `#练琴` 标签的笔记，希望每周 3 次。

时间带上缺的那几天，就是那几天没碰。
