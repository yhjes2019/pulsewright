# 隐私与数据

## 三个不

- **不联网。** 两端都不发任何网络请求。
- **不注册。** 没有账号，没有激活码，没有许可证校验服务器。
- **不改你的笔记内容。** Obsidian 端只读 `.md` 的正文和属性。

Zotero 端会写东西，但只写**子笔记**——也就是它自己新建的那条，不碰你原有的字段、标签、批注。

## 数据都在哪

### Obsidian 端

```
<你的库>/<数据目录>/         # 默认 Pulse
<你的库>/<数据目录>/导出/     # 分享卡 PNG / SVG
```

里面是日统计缓存、速记、惦记配置、导出文件。**笔记正文一律不写入。**

想彻底清干净：禁用插件，删掉那个目录。

### Zotero 端

没有独立数据文件。你的作答写在对应文献的子笔记里，笔记开头带：

```html
<!-- pulsewright-six -->
```

好处是它跟着 Zotero 库一起同步、一起备份。坏处是你得知道它在那儿——删掉那条子笔记，等于清空那篇文献的六问答案。

## 导出时的脱敏

导出的 JSON 默认**不含**设置、**不含**速记内容。这两个默认是关的：

- 「导出含设置」— 关
- 「备份含速记」— 开之前想清楚

分享卡只含八项统计数字，不含任何笔记标题。

## 它读了你什么

**Obsidian 端**：文件路径、修改时间、创建时间、正文（算字数和链接）、frontmatter（按你配置排除）。

**Zotero 端**：标题、摘要、类型、期刊、年份、DOI、标签、分类、批注、有没有附件。

两端都只读，都不上传。这不是「我们先收集再承诺不卖」——是没有收集这一步。
