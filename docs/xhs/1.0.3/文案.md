**正文**

1.0.3 发了。

之前打开是九个并列的页签，写着写着我自己也不知道该点哪个。这一版把入口收了——打开只剩一屏：

**一句话**：今天写了多少、动了哪几篇、连着几天。每个数字都带参照，不让你对着一串数字猜好坏。
**一条带**：最近 12 周，中间缺的那块就是那几天没写。
**一件事**：一篇你很久没碰的笔记，接着写，或者先放着。

新加的叫「惦记」。你说你在意的几件事（练琴、英语、某个项目），它替你看着哪条悄悄停了。它只说一句话，还会给你「推迟」这个选项——比「你落后了」好听得多。

顺手把洞察页从 158ms 提到 61ms，删了一批死代码，换了个配色。

一直是那个原则：只数数字，不读内容，不联网，零授权校验。

免费，MIT，Obsidian 社区市场搜 Pulsewright。
从 1.0.2 升上来不用重装，设置里点一下刷新就行。
