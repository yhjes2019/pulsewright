## 小红书

**标题（选一个）**

1. 我给它加了个 Zotero 端：存了三百篇，还是没读懂
2. 每篇文献七个问题，问完才算读过
3. 一个不替你下判断的文献插件

**正文**

1.1.0 发了。这次不是给 Obsidian 加功能，是补上另一半。

我发现自己存了两百多篇文献，真正读进去的没几篇。问题不在没时间，在于存下来那一刻，就已经当自己读过了。

所以做了「六问」。选中一条文献，按一下，七段问题从上到下：

**一、这本文献讲了什么** —— 类型、期刊、年份、摘要，它自己带出来，不用你抄。
**二、我为什么选它** —— 你写一句话。旁边的提示只给事实：哪天加的、在哪个分类、什么标签、有没有 PDF。
**三、库里有相关的吗** —— 按词面相似度排，给百分比。我那个十四篇的测试库里，这篇有八篇跟它主题相近，最像的一篇 17%。
**四、有没有更优解** —— 拿最像的那篇并排：年份、类型、来源、有没有摘要。它不下判断，只把两列事实摆出来。
**五、读完还有哪些问题** —— 写下来，存进这条文献的子笔记。
**六、下一本该读什么** —— 从库里挑三篇，标出「同类型」「更新」。
**七、你的阅读痕迹** —— 批注数、附件、最近改动。

右上角有「上一篇 / 下一篇」，按你文献列表当前的排序走，可以一篇篇读下去，不用关掉再点。

答案写在这条文献自己的子笔记里，跟着 Zotero 库同步走。不另建数据库，关掉插件答案还在。

它不联网。只调 Zotero 自己的条目接口，一个请求都不发。

Obsidian 那边这版也顺手改了两处：切页签会记住你上次滚到哪，十五分钟一次的后台扫描没变化时不再重写索引（实测从 14ms 的写盘降到 0）。

免费，MIT。Obsidian 社区市场搜 Pulsewright；Zotero 端装一个 xpi，工具 → 插件 → 齿轮 → Install Plugin From File。

## 即刻 / 微博 / X

1.1.0 发了，这版多了一个 Zotero 端。

核心是「六问」：一条文献七段问题——讲了什么、我为什么选它、库里哪篇相关、有没有更优解、读完还有哪些问题、下一本该读什么、我的阅读痕迹。答完才算读过。

库里有 8 篇相近的会按相似度列出来给百分比；最像的那篇并排对照年份、类型、来源、有没有摘要。不替你判断，只摆事实。答案存进文献的子笔记，跟着库同步。不联网。

Obsidian 端也顺手改了两处：切页签记住滚动位置，后台扫描没变化就不再重写索引。
