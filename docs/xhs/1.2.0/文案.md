**正文**

1.2.0 发了。这版没加视图，只修一个很笨的问题。

之前装完插件打开，面板上全是 0 和一句「还没有索引到笔记」。它说的是实话，但等于什么都没说——用户看完这一屏，就把插件关了，再也不打开。我自己测的时候也是这样，只是我当时知道它是好的。

所以这版做了两件事。

**一、空库先给你一张三步卡。**

1. 写点什么——点「新建一篇笔记」，哪怕只写一行。
2. 回来看一眼——这里会记下今天写了多少字、动了哪几篇。
3. 攒够几天——概览、知识地层、月相日历会自己长出来。

不想先写，点「先看看示例数据」，立刻能看到满屏的样子：87 天、16 篇、有断链、有标签、有周报。

示例数据只活在内存里：不写进你的库，不进 `data.json` 的历史，不进分享卡。顶上有条横幅写着「这不是你的库」，点「回到我的库」还原，一个字符都没动过你的文件。

**二、一条能直接发出去的周报。**

今天页底部多了两个按钮：

- **导出这一周的图**——1080×1440 的周报 PNG，落在 `Pulse/导出/` 里，另存一份 SVG。
- **复制周报文字**——把这一周写成一段话，粘哪都行。

图里只有统计：本周得分、活跃几天、新增多少字、几篇笔记、几处链接、最厚的一天。**不带你任何笔记标题**，所以敢直接发出去。

周按 ISO 周算（周一到周日），报告日期取今天，不会出现「一周还没过完就写截至周日」这种假话——这是我自己测出来的 bug，改了。

数据页也有同一张周报卡，两个按钮一样。

还顺手改了一处：分享卡在只有 7 根柱的时候柱子太细，现在按天数自适应，一周的图不会像一排牙签。

免费，MIT，全本地，不联网，没有激活码。Obsidian 社区市场搜 Pulsewright，或者去 Releases 下 exe / zip。

## 一条英文（可选，配合 GitHub Release）

Pulsewright 1.2.0 — the first-open fix.

An empty vault no longer greets you with a wall of zeros. There is a three-step card (write something, come back, give it a few days) and a "peek at sample data" button that fills the whole panel with 87 days of made-up notes — memory only, never written to your vault, never in the share card.

Also new: export the current week as a 1080×1440 PNG from the Today view, or copy it as text. Statistics only, no note titles.
